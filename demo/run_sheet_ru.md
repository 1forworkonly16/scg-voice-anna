> **Заменено 2026-10-06 видеотреком:** встречи с Димой не будет, для SCG записываем частное видео (`docs/decisions.md`, «Goal: private video»). Шпаргалка оставлена для справки; сценарий видео — `demo/video_run_sheet_ru.md` (фаза B). С 2026-10-06 Анна не спрашивает согласия на хранение данных («No consent question»), строка 1:35 обновлена.

Для консультанта. Диме вопросов не задаём, показываем пользу. Демо идёт **с вашего телефона на громкой связи**, только по-русски. Данные в звонках выдуманные; «Parauga iela 7» — ДЕМО-дом. Реплики: `docs/scenarios.md`; итоги дня: `demo/digest_trigger.md`.

## Подготовка (за 30–60 минут; ноутбук, папка `Dima voice`)
0. **Баланс кредитов:** `npm run el:credits`. Остатка должно хватить на 6 минут разговора по ставке, измеренной на H3 (`docs/live_checklist_M1.md`, раздел Credits). Мало кредитов: тестовый звонок (шаг 3) пропустить. Pay-as-you-go не включать.
1. `npm run link:unlock` печатает ссылку talk-to. Открыть её на **своём телефоне** через **мобильный интернет**.
2. **Предполётная проверка** в PowerShell: `Set-ExecutionPolicy -Scope Process Bypass -Force`, затем `. .\scripts\env.ps1`, затем `$u = 'https://scg-voice-demo.scg-voice-demo.workers.dev'; $h = @{ 'x-admin-key' = $env:SCG_ADMIN_KEY }`. Затем по порядку:
   - всегда сбросить график ДЕМО-дома: `Invoke-RestMethod "$u/admin/demo/reset-works" -Method Post -Headers $h`;
   - `(Invoke-RestMethod "$u/admin/health?deep=1" -Headers $h).deep | ConvertTo-Json -Depth 4`. Везде должно быть `true`;
   - один прогревочный вызов слотов (холодный старт ≈ 11 мс CPU при лимите Free 10 мс): `Invoke-RestMethod "$u/tools/get_slots" -Method Post -Headers @{ 'x-scg-key' = $env:SCG_TOOL_KEY } -ContentType 'application/json' -Body '{"conversation_id":"[TEST]-warmup","language":"ru"}'`. Должны прийти слоты.
3. **Один тестовый звонок** (около 1 минуты, на осмотр не записываться): «Ilūkstes iela 16, сколько стоит?». Анна по-русски сразу говорит, что она ИИ-ассистент (о записи разговора ни слова: звук не записывается), называет 141 квартиру, после «Да» даёт цену с «ориентировочно». Этот звонок войдёт в итоги дня.
4. На телефоне включены уведомления группы «заявки(демо)». Календарь «SCG — Бесплатный осмотр» виден в Google Календаре. QR `demo/join_qr.png` под рукой.
5. Громкость на максимум, громкая связь, автоблокировка и «Не беспокоить» выключены. **Резервное видео** (записано на H3) сохранено на телефоне офлайн.

**Перед стартом:** Дима сканирует QR и вступает в группу «заявки(демо)». Тогда уведомление придёт на **его** телефон.

## Если Дима спросит
- **«Разговор записывается?»** — «Звук не записывается, только текст для заявки.»
- **«А по-латышски?»** — «Латышский тоже есть; в демо показываем русский, латышский доводим к пилоту.»

## Если что-то пошло не так
- **Ссылка не соединяется:** `npm run link:status`, затем снова `npm run link:unlock`. Если кредиты закончились, показываем резервное видео.
- **Сеть:** переключить Wi-Fi и мобильные данные или раздать интернет со второго телефона. Сети нет совсем: резервное видео.
- **Эхо или Анна перебивает:** убавить громкость, отодвинуть телефон от ноутбука, говорить короче и без долгих пауз посреди фразы.
- **Анна ответила на вашу фразу для Димы:** ничего не объяснять, просто следующая реплика по сценарию.
- **Номер расслышан не так:** спокойно повторить теми же группами. Если не хватает цифры, Анна сама переспросит.
- **Анна спросила «Алло, вы меня слышите?» и замолчала:** так и задумано — после одного вопроса она ждёт молча. Просто скажите следующую реплику.
- **Telegram не пришёл:** показать событие в календаре, сообщение придёт следом. Не записываться повторно.
- **Анна ошиблась:** «Это демо; в пилоте настраиваем на ваших реальных звонках», и дальше по сценарию. Сама заговорила по-латышски: «Давайте по-русски» и дальше по-русски.

## Пилот: что сказать Диме
- «В пилоте этот же ассистент отвечает на ваш настоящий номер — когда никто не берёт трубку или после 17:00».
- **Номер:** латвийский +371, оформленный на SCG по документам компании. Ваши мобильные остаются, включается переадресация (нет ответа / занято / вне рабочего времени).
- **SMS-подтверждения** появятся в пилоте вместе с номером. В демо подтверждение — то, что Анна прочитала вслух.
- **Перевод на человека:** в пилоте Анна соединяет с офисом или дежурным мастером. Сейчас она записывает обратный звонок.
- **Данные:** звук не записывается; текст разговоров хранится 90 дней, доступ только у SCG, аккаунты на SCG, договор обработки данных (DPA) с сервисами, хранение в ЕС там, где сервис это позволяет. Пилот 30 дней бесплатный.
